# Android CMS 文件签名文案审批

仅新增 CMS 文件签名入口；保留现有“文件签名”的原始签名流程及文案。下列新增文案待 Owner 批准后才进入运行时。

| 屏幕 / 键 | 修改前 | 修改后 | 原因 |
| --- | --- | --- | --- |
| PIV 操作列表 / PIV_CMS_SIGN.title | 无 | CMS 文件签名 | 区分现有原始签名入口。 |
| CMS 文件面板 / signing_cmsRequirements | 无 | 需要有效的文档签名证书，且证书公钥与所选槽位一致。 | 在操作前说明证书要求。 |
| CMS 文件结果 / signing_cmsVerified | 无 | CMS 签名验证：通过 | 仅在原文件与所选证书的签名验证通过后显示。 |
| CMS 文件结果 / signing_cmsScope | 无 | 导出 .p7s 独立签名，包含签名证书；验证时还需原文件。原文件保持不变。 | 说明文件格式、证书内容及原文件依赖。 |
| CMS 文件结果 / signing_cmsTrust | 无 | 未验证证书信任链、吊销状态或可信时间。 | 避免把签名正确等同于身份或信任认证。 |

复用已批准的“选择文件”“选择非空文件，最大 1 MiB。”、“导出”和现有 PIN 确认、导出成功／取消／结果未知文案。拒绝不符合文档签名条件的证书时，复用现有输入无效错误；公钥不匹配复用现有公钥不匹配错误。CMS 签名验证结果与输出文件保存结果分别显示。
