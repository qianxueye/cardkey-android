# Material passkey asset

`app/src/main/res/drawable/ic_approved_passkey.xml` preserves the original Google Material Symbols passkey path. Native import changes only the coordinate transform: translate Y by 24, scale X/Y by 0.025, and use the surrounding icon tint. The displayed size remains at least 24dp.

Approved source package: CardKey approved icon candidates, 2026-10-26, `passkey.svg` and `material-passkey-original.svg`.

Upstream source: https://fonts.gstatic.com/s/i/short-term/release/materialsymbolsoutlined/passkey/default/24px.svg
